منسّق JSON

التحقق من JSON وتنسيقه أو ضغطه ومعرفة موضع الخطأ.

تحتاج هذه الأداة إلى تفعيل JavaScript في المتصفح.

ماذا تفعل الأداة

تحلّل الأداة نص JSON بمحلّل المتصفح الصارم، ثم تعرضه بمسافتين أو أربع مسافات للإزاحة أو في سطر واحد مضغوط. وإن كان الإدخال غير صالح فتُعرض رسالة الخطأ الصادرة عن المحلّل لتحدّد موضع المشكلة.

طريقة الاستخدام

الصق JSON في مربع الإدخال، ثم اختر حجم الإزاحة أو الضغط، فيظهر الناتج المنسّق في مربع الناتج.

حدود يجب أن تعرفها

JSON الصارم فقط: تُرفض التعليقات والفواصل الزائدة والنصوص بين علامتي اقتباس مفردتين. وتظهر رسالة الخطأ بالإنجليزية لأنها تصدر عن المتصفح نفسه. وقد تفقد الأعداد الصحيحة الكبيرة جدًا دقتها لأنها تُحلَّل كأعداد JavaScript.
