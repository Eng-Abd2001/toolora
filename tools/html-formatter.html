HTML Formatter

Indent messy HTML so it is readable, or minify it for production.

This tool needs JavaScript. Please enable it in your browser.

What it does

Puts each tag on its own line and indents by nesting depth, using 2 spaces, 4 spaces or tabs. Minify removes comments and the whitespace between tags.

How to use it

Paste HTML, choose a format and copy the result.

Limits worth knowing

This is a simple formatter, not a validator, and it does not repair unclosed tags. Inline tags such as <b> also get their own line, whitespace inside <pre> is not preserved, and scripts or styles that contain a < character may be split in the wrong place.
